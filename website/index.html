WorkMami 是什么
把散落在多个 WorkBuddy 账号里的额度、任务和签到，收进一个顺手的管理台

WorkMami 是一款第三方独立开发的本地桌面工具，专为同时使用多个 WorkBuddy 账号、又想把这些账号的能力复用到其它客户端的重度用户打造。它不改动、不侵入 WorkBuddy 官方服务，只是在你自己的电脑上帮你把账号、额度、任务和签到管得明明白白。

  • 多账号统一掌控：一个界面添加、切换、批量签到，看清每个账号的余额与积分。
  • 模型本地反代：把 WorkBuddy 模型以 OpenAI 兼容接口暴露出来，接入任意支持自定义模型的客户端。
  • 日常琐事自动化：签到、派猫猫旅行领奖励，后台按时巡检，还能自动降频防风控。
  • 数据尽在掌握：Token 看板、用量统计、会话跨账号迁移与整库备份，透明可控。

核心功能
六大模块，覆盖账号、模型、任务、数据的全流程

账号管理

通过 OAuth 网页授权添加多个 WorkBuddy 账号，安全存储加密凭证。按昵称区分账号，一键切换、随时查看每个账号的额度与积分明细。

本地反代

把 WorkBuddy 的模型以标准 OpenAI 兼容接口在本机反代出来，供任意支持自定义模型的客户端接入。真流式透传、智能选号、粘性会话与模型回落，长任务稳定不断流。

签到中心

一键为所有账号批量签到，自动检测当日是否已签、防止重复。可开启后台定时自动签到，日常额度领取不漏一次。

猫猫旅行托管

每天自动派猫猫出行、到站领取奖励，并清晰展示"派出于 / 奖励领于"的具体时刻。后台每 60 分钟巡检，连续确认全部账号达当日上限后自动熔断，避免高频调用触发官方限制。

Token 看板

各账号余额随时间变化的折线图、反代调用流水与用量统计，积分清单双口径归因，让你一眼看清额度都花在了哪里、哪个账号更划算。

数据管理

支持会话在账号之间迁移归属、整库备份与导出，全部数据保存在本地。换机、整理账号都能从容操作，数据始终握在自己手里。

下载对应芯片的 .dmg
Apple 芯片下 aarch64，Intel 下 x64。双击打开 dmg，把 WorkMami 图标拖进"应用程序(Applications)"文件夹。

首次打开若提示"已损坏 / 无法打开"
由于本工具未做付费签名与公证，macOS 会给下载来的 App 打上"隔离标记"。这不代表文件真的损坏，在"终端"里执行下面命令清除标记即可（永久解决）：
xattr -cr /Applications/WorkMami.app复制
若提示权限不足，改用带 sudo 的版本：
sudo xattr -rd com.apple.quarantine /Applications/WorkMami.app复制

在"应用程序"里右键点击 WorkMami → 打开 → 再点"打开"，即可绕过一次性的安全提示。

常见问题
反代出来的模型怎么接入其它客户端？

在 WorkMami"代理设置"里开启本地反代服务，会得到一个 OpenAI 兼容的接口地址与 API Key。在任意支持"自定义模型 / OpenAI 兼容接口"的客户端里，填入该地址、Key 和模型名即可像调用官方模型一样使用。

执行长任务时会不会中断？

反代采用真流式透传，并对长连接做了专门的超时处理，长时间生成的任务不会被中途掐断。若个别请求仍异常，本机数据目录下的诊断日志会自动记录，便于排查。

猫猫旅行会不会太频繁导致账号被限制？

后台每 60 分钟才巡检一次；当连续确认所有账号当天都已达到派猫猫上限后，会自动熔断、当天不再轮询，尽量降低对官方接口的调用频率。

需要 WorkBuddy 官方账号吗？收费吗？

WorkMami 本身免费，但它管理的是你自己的 WorkBuddy 账号，使用前你需拥有并登录自己的 WorkBuddy 账号。所有额度消耗都发生在你自己的账号上。

这是 WorkBuddy 官方软件吗？

不是。WorkMami 是第三方独立开发的本地效率工具，与 WorkBuddy 官方无任何隶属或背书关系。请遵守 WorkBuddy 官方服务条款合理使用。
